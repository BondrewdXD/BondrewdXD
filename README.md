Soy **Jose Miguel Vera Garzón** estudiante de Ingeniería de Sistemas con interés en el desarrollo de software, arquitectura de aplicaciones, sistemas distribuidos, bases de datos e inteligencia artificial.

Durante mi formación académica he trabajado en diferentes proyectos orientados al desarrollo de aplicaciones web y móviles, construcción de APIs REST, integración con bases de datos y diseño de soluciones utilizando arquitecturas modernas.

Me interesa especialmente comprender cómo diseñar sistemas escalables, mantenibles y preparados para funcionar en entornos distribuidos.
